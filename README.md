Arise UI is a shadcn registry built with Next.js, Tailwind CSS, and TypeScript. Every component is animated with Motion, honors `prefers-reduced-motion`, and installs straight into your codebase. You own the code: no package to depend on, restyle anything.

## Quick start

Install any component with the shadcn CLI:

```bash
npx shadcn add swamimalode07/arise-ui/{component-name}
```

For example:

```bash
npx shadcn add swamimalode07/arise-ui/fluid-orb
```

Browse every component, with live previews and props, at [ariseui.com/components](https://ariseui.com/components).

## Running locally

```bash
git clone https://github.com/amitgajare2/ariseui.git
cd arise-ui
npm install
npm run dev
```

Components live in `components/ui`. After changing a component or `registry.json`, rebuild the registry output with `npm run registry:build`.
